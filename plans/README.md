## Findings considered and rejected

- Splitting `registerTools.ts` / `projectStore.ts` into modules: single-file
  registry is the app's stated showcase; the real harm (duplicated color policy)
  was fixed by plan 008 without a split.
- PWA/offline install: not grounded in repo evidence — noise.
- `get_tilemap` legend collision after 64 distinct tiles: fixed with two-character tokens.
- ChatGPT in-app browser iframe permissions-policy messaging: deferred until tested
  in the real ChatGPT embed environment.
- `bresenhamLine` NaN infinite-loop path: no reachable caller (no line tool).
- A full CRDT rewrite: not justified while the current room model can be made
  reliable with an outbox, identity-aware merges, and bounded patches.
- Automated tests in this pass: explicitly deferred by the maintainer decision;
  test targets remain recorded in each plan.
